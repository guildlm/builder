THE DOSE QUESTION, ANSWERED BY A ONE-LINE EDIT (18:14)
=======================================================
The obvious objection to everything above: perhaps ANY spec edit perturbs everything, and
twelve lines are not special. The corpus already contains the control — `11520cc` changed
exactly ONE LINE of specs/taskflow.yaml, a test name, with draws either side on server 4439

    taskflow-chain5  (14:48 log)  contains TestSortedProjectList   — after it

    11c11
    < func TestProjectListSorted(t *testing.T) {
    > func TestSortedProjectList(t *testing.T) {

Same byte count on both sides, 5326, because the two names are the same length.

    A ONE-LINE SPEC EDIT IS SURGICAL: 11 of 12 untouched files byte-identical, and the twelfth
    carries precisely the change that was asked for, in precisely one line.

    TWELVE ADDED LINES ARE NOT: 4 of 7 untouched files differ, and NONE of them is the file
    the twelve lines are about. config.go, service.go, models_test.go and
    middleware_chain_test.go are collateral — the lines live in the projects TEST entry.

    So the effect is not "editing a spec disturbs the draw". It is specific to ADDING BULK.
    A targeted one-line change reaches exactly its target; twelve lines of added prose reach
    files the entry never mentions and leave the target's own defects in place.

⚠️ TWO EDITS, ONE SPEC EACH, AND THEY ARE DIFFERENT SPECS. taskflow for the one-line arm,
taskapipro for the twelve-line arm. So "surgical vs collateral" is not a controlled contrast

has a twelve-line addition to taskflow. What is controlled within each arm is the server, the
