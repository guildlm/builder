THE TWO FIXES
    FIX 1 — run the plan-conformance check REGARDLESS of green.
        `_fill_empty_planned_files` and the "WARNING: ... shipped EMPTY" loop both live inside
        `_finish_green()` (builder.py:5526). A project that never converges gets NEITHER. Move at
        minimum the WARNING out, so an empty planned file is always recorded.
        ⚠️ MINIMAL VERSION FIRST: the warning only. Moving the REPAIR out is a behaviour change on
        failing builds and should be its own arm — a repair that fires on a broken tree and then
        cannot pass toolchain.check will revert anyway, so it buys nothing until hole 1's warning
        shows how often the case arises.

    FIX 2 — broaden `_required_decls` beyond `Name struct|interface`.
        _REQUIRED_TYPE_RE = r"(?<![.\w])([A-Z]\w*)\s+(?i:struct|interface)\b" cannot see a type named
        in backticks. ledger's memory.go entry writes `MemStore` that way, so the extractor yields
        only {Store} — which store.go owns — and take is empty.
        Proposed addition: capitalised identifiers inside backticks in a purpose.
        ⚠️ THIS WIDENS WHAT THE HARNESS THINKS A FILE MUST DECLARE, which feeds generation prompts
        (5130), the fix loop (5412) and the redeclaration stripper. It is NOT a local change and its
        blast radius is larger than fix 1's.
