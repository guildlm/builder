WHY NOTHING CAUGHT IT
A stub file compiles, vets and tests clean. `go build` is happy. The suite is green. The
mutation sweep finds no sites in a file with no code and therefore reports nothing about it —
absence of rows reads as absence of holes. And the spec audits in this repo check test NAMES
and promised guards, not whether the file a spec entry describes actually received its content.

    Every instrument passed an artifact that had silently reorganised itself, and the only
    reason it surfaced is that a row stopped joining across generations.
