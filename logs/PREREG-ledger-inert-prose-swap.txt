WHY THIS EDIT AND NOT A LINE ADDITION
It is the closest possible analogue to the name swap just run — equal length, semantics-preserving,
a reordering of two words — differing ONLY in WHERE it sits: prose describing imports, rather than
a test's name. That isolates location from size. A line addition would change size too and confound
the comparison with the dose arms.

    Inertness argued, not assumed: Go sorts imports and gofmt would reorder them regardless, and
    the spec's sentence names a SET ("import exactly X, Y, Z"). The order carries no meaning.
    ⚠️ The tool cannot check this — it only guarantees no character was added, dropped or altered.
    The semantic judgement is mine and is recorded here so it can be held against me.

    The taskflow analogue of this exact manipulation — "(sync, sort, errors as needed)" ->
    "(sort, sync, ...)" — PERTURBED, 6 CODE files and 8 functions.
